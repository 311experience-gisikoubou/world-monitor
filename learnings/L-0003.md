# L-0003: 共通ルールの重複・類似・陳腐化を検出し統合案を提示する。正本変更は人間承認後

- ID: L-0003
- Title: 共通ルールの重複・陳腐化検出と統合提案
- Status: active
- Scope: common
- Approved: 2026-08-17

## Trigger（発動条件）

共通正本（`AGENTS.md`・`CORE.md`・`OPERATIONS.md`・`learnings/`・`.agents/skills/`等）へ、新しい共通ルール・共通スキル・共通学習を追加または変更しようとした時点で必ず発動する。

重複・類似・古い記述が「疑われる時」だけに限定しない。AIまたは人間が「今後すべての開発で使う」「共通化する」「他repositoryへ横展開する」と判断した時点で、正本へ書き込む前に`common-rule-integration-audit`を実行する。

## Rule（内容）

「新しい共通ルールを思いついた = 新規追加」にはしない。

AIは書き込み前に既存正本を検索し、重複・類似・矛盾・陳腐化・scope誤り・既存ルールへの統合可能性を監査する。監査結果は`MERGE_EXISTING` / `NEW_COMMON` / `LOCAL_ONLY` / `REJECT` / `HUMAN_DECISION`のいずれかとして提示する。

既存ルールへ統合できる場合は新規ルールを増やさない。repository固有ならcommonへ昇格せず`AGENTS.local.md`等へ置く。不要・過剰・既存原則を弱める場合は採用しない。

自動削除・自動統合・正本の自動変更は禁止。反映は必ず人間承認後に行う。禁止事項・セキュリティ・個人情報保護・人間確認条件・高リスク操作条件は、要約・統合によって意味を弱めてはならない。
