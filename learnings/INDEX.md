# Learnings Index

このディレクトリ（`learnings/`）は、`ai-dev-foundation`の学習記録の正本です。
1学習1ファイル（`L-XXXX.md`）とし、本ファイルはそのうち`status: active`のものだけを一覧化します。
`deprecated`・`superseded`の学習はこの一覧に載せません（該当ファイルで経緯を確認してください）。

## 記録・参照上の原則

- 個人情報・秘密情報・認証情報・トークンは、このディレクトリ配下のいずれのファイルにも記録しない。
- AIはこのディレクトリを自動更新しない。学習候補は「⚠️ 学習候補」として提示し、人間承認後にのみ`L-XXXX.md`を追加・修正する（詳細はL-0002）。
- AIはまず本INDEXの一覧を確認し、該当する学習があれば当該`L-XXXX.md`を読む。
