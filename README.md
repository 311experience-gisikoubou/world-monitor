# World Monitor（世界情勢ダッシュボード）

## 結論：ネットで見たWorld Monitorの更新をそのまま使う

**Windowsでは `start-world-monitor.cmd` をダブルクリックするだけ。**
公式サイト https://www.worldmonitor.app/ を既定のブラウザで開きます。
`Open-Official-WorldMonitor.url` をダブルクリックしても同じです。

公式サイトを直接利用することで、**このリポジトリに静的データや独自の疑似画面を表示するのを避けます**。
ただし、公式サイトでも「すべてが秒単位で動く」わけではありません。

## 「リアルタイム」の正確な意味

公式ドキュメントでは、データの種類ごとに更新間隔が違います。

| データ | 公開されている設計上の取得間隔（目安） |
| --- | --- |
| 株価・暗号資産 | 1分 |
| ニュース・地震・軍事追跡 | 5分 |
| 気象警報・航空遅延 | 10分 |
| インターネット障害 | 60分 |
| 船舶AIS | WebSocketによる逐次受信（APIキー・接続条件に依存） |

公式の無料ダッシュボード全体のリフレッシュ頻度は通常 **5～15分程度**と記載されています。上の数字は内部設計の目安で、すべての無料表示に適用される保証ではありません。情報提供元の遅延・障害やブラウザの省電力動作でも変わります。

## 自分のPCで公式ソースを起動したい場合（開発用途・上級者向け）

開発元 `koala73/worldmonitor` のアプリ本体は、Gitサブモジュール `official/` で特定コミットに固定して参照します。

1. Git と Node.js 22以上を準備します。
2. `start-local-world-monitor.cmd` を起動します。
3. 初回は公式ソース・npmパッケージを取得し、開発用の `http://localhost:3000/` を開きます。

**注意：ローカル開発版は公式サイトと同じライブデータを保証しません。** APIキーがない項目やRedis・リレーなどサーバー側の準備が必要な項目は、空欄・古いデータ・エラーになる可能性があります。すべてをセルフホストするには公式 `SELF_HOSTING.md` に従う必要があります。無断で有料サービスは契約しません。

## 調査結果

2026-10-09時点、修正前の `main` は、AI共通基盤の設定が主で、アプリ本体の `src/` や `package.json` がありませんでした。したがって公式サイトと同じ画面・データ更新を提供する状態ではありませんでした。

今回の変更では、**公式サイトを開く安全な経路を標準**にし、ローカル開発は別の入口として残します。機密・患者・医院・料金情報へのアクセスは行いません。AI共通基盤の設定ファイルは変えていません。
